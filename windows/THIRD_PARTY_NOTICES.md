# Third-party notices

The optional local image-understanding feature downloads and runs the following open-source model on the user's computer:

- SmolVLM-256M-Instruct by Hugging Face, licensed under Apache License 2.0: https://huggingface.co/HuggingFaceTB/SmolVLM-256M-Instruct

Local inference is provided by Transformers.js, also licensed under Apache License 2.0:

- https://github.com/huggingface/transformers.js

The model is not bundled in the source repository or installer. It is downloaded from the official Hugging Face repository only when the user prepares or first uses local image recognition.
