# DeepSeek yu Windows 客户端

运行 `npm run build` 生成独立的 Windows 客户端。客户端会连接本机的 Harness，并在需要时自动启动 Harness 与仅限局域网访问的手机网关。

每台电脑首次运行时会要求使用者填写自己的 DeepSeek API Key，随后随机生成本机端口、手机端口和手机连接保护密钥。所有值仅保存在应用数据目录；源码、Android APK 和安装包不包含固定密钥或固定端口。

工作区文件夹统一使用 Harness 的应用内目录浏览器，避免打包环境中 Win32 原生目录对话框子进程异常退出，并兼容电脑端和手机端。

## v1.1.3 正式版：成长型动态桌宠与 DeepSeek Harness 一键更新

- “设置 → DeepSeek yu → DeepSeek Harness 更新”增加检查更新、一键更新到最新版，以及安装指定官方版本。
- 更新页同时显示 npm 的 `latest`/`next` 标签、核对时间和完整发布历史，并按完整语义版本排序；例如 `0.1.1-rc.2` 新于 `0.1.0-rc.8`。低于客户端兼容线的旧版只供查看，不允许误操作降级。
- 更新来源严格限制为 DeepSeek 官方 npm 命名空间，完成后重启客户端生效。
- 桌宠增加投喂、玩耍、拖拽、睡眠、升级和随机待机动作。完成一次工作获得 1 条小鱼干，执行过命令的工作获得 2 条；投喂会增加成长经验并解锁四个阶段。
- 文件可拖到桌宠上，经确认后由 Windows 移到回收站；不处理文件夹，并可在设置中关闭。
- 余额旁可显示当前高峰/空闲时段，并可单独关闭。时段按用户提供的计费表：北京时间工作日 09:00–12:00、14:00–18:00 为高峰。
- 延续 v1.1.2 的社区插件检查更新、本地识图独立页面和紧凑桌宠聊天框。

## v1.1.2 正式版：插件修复与启停

- 插件兼容检查不再依赖 GitHub API 的默认分支接口；API 限流时仍会从仓库常用分支读取安装说明并选择真正声明 `dsh.bundle` 的 npm 包。
- 已安装插件支持“启用”和“禁用”。禁用只移出 Harness bundle 挂载列表，不删除插件文件；重新启用后重启客户端即可恢复。
- “社区插件”可一键检查 npm 或 GitHub 来源的最新版本，并对有更新的插件逐个确认更新；更新会保留原来的启用/禁用状态。
- 设置左侧提供独立“本地识图”页面，可查看 SmolVLM 模型缓存状态、下载或加载模型、打开模型目录并选择图片测试；图片仍只在电脑本地分析。
- 对下载成功但没有 `dsh.bundle` 的仓库根包显示“修复”。修复会先安装并验证 README 推荐的可挂载插件，再移除旧的未激活依赖。

## v1.1.1 正式版：完整插件发现与生命周期管理

- 插件市场聚合已验证目录、[DSH Market](https://dsh.market/) 和 GitHub [`dsh-plugin` Topic](https://github.com/topics/dsh-plugin)，按仓库去重，并显示每个条目的来源和验证状态。
- 修复安装包内 pnpm 命令入口缺失导致插件安装失败的问题，并正确解码 Windows 中文命令输出，避免错误信息乱码。
- 对需要构建脚本的插件保持默认阻止；只有用户二次确认后，才把准确的包名写入当前 Harness profile 的 `allowBuilds` 并重试。
- “社区插件”成为设置左侧独立页面，切换时完全隐藏上一页；页面会区分已挂载 bundle、未激活普通依赖和安装不完整项，并支持确认卸载。
- 安装 GitHub 条目前先检查仓库根包是否声明 `dsh.bundle`；对于 monorepo/插件集合，会读取仓库 README 的官方安装命令并优先改用真正可挂载的 npm 包。安装完成后再次核验 profile，避免“下载成功但 UI 没变化”。

## v1.1.0 正式版：官方版本同步与 Harness 插件

安装包内置独立 Node.js 运行时，不要求使用者另外安装开发环境。客户端会自动把旧版 DeepSeek 密钥文件迁移到官方 v1 凭据格式，密钥值保持不变且不会写入安装包或 Git。

客户端、安装包、快捷方式、窗口、托盘、桌宠和 Harness 页面统一显示为 `DeepSeek yu`。为了兼容旧版本，应用 ID 和数据目录保持不变，升级不会主动清空本机密钥、视觉模型或会话记录。

- 默认集成 DeepSeek 官方 `@deepseek-ai/dsh 0.1.1-rc.2`，包含 DeepSeek-V4-Flash、DeepSeek-V4-Pro 和实验视觉模型。客户端的“官方更新与插件市场”可查看并选择 DeepSeek 官方 npm 版本；安装后重启生效。
- 桌宠现为可安装的 Harness bundle 插件，负责在 Harness 页面连接当前会话；独立透明窗口可拖动、置顶、调节大小和透明度，并随 Harness 的思考、命令执行、完成、错误切换动作。
- 桌宠下方的面板会同步当前 Harness 会话、工具执行进度和最终回复，也可直接输入消息。
- 主聊天框使用 Harness 原生的“＋”、图片缩略图、附件存储和消息记录；官方模型声明支持图片时由官方适配器处理，文本模型则由 Harness Host 内部的 SmolVLM 服务生成文字描述，DeepSeek 适配器只发送该描述。
- 余额与服务状态是独立 Harness bundle 插件。密钥只在 Harness 后端按操作读取，网页端只接收余额、官方服务状态、延迟和 429/503 等经过清理的结果，不接收密钥明文。
- 新增第三方插件市场，数据来自独立社区目录。目录明确标注非 DeepSeek 官方或认可；每次安装前展示源码、安装项与代码执行风险，并要求使用者确认。
- 无需火山方舟或其他视觉 API Key。第一次识图需下载约 270 MB 的 Apache-2.0 免费模型，模型缓存完成后可离线使用。
- 手机端也使用同一套 Harness 附件入口：图片经受保护的局域网连接进入电脑上的 Harness，再由内部本地视觉服务识别，不在 Android 设备上重复下载模型。
- 已移除网页层的图片选择拦截和手机端专用识图接口；普通文件仍按 Harness 原来的文件流程处理，界面没有单独的识图按钮。
- 手机版增加底部导航、侧滑会话抽屉、全屏设置、触控尺寸、软键盘适配和连接状态；Android 图片选择器、下载和外部链接也由客户端安全处理。
- 手机端插件页通过已认证的局域网控制通道连接电脑，因此可以查看余额与服务状态并管理桌宠、官方 Harness 版本和社区插件；安装或打开电脑目录等敏感操作仍在电脑端执行或确认。
- 默认点击主窗口右上角“×”只会缩到后台，桌宠继续运行；从 Windows 托盘菜单选择“退出”才会完全关闭。此行为可在“设置 → DeepSeek yu → 桌宠”中关闭。
- 自定义桌宠放在设置页打开的用户桌宠目录中。格式说明见应用内置的 `assets/pets/README.md`。

从旧版升级时，已经保存的豆包/火山方舟视觉密钥文件会被删除。只有从托盘菜单完全退出后，客户端启动的 Harness 和手机网关才会一并停止。

“服务状态/拥堵”综合 DeepSeek 官方状态页、本机请求延迟和 429/503 响应；“高峰/空闲时段”则只按设置页注明的北京时间表计算，二者互不混用。

生成后的主程序位于 `dist/DeepSeek yu-win32-x64/DeepSeek yu.exe`。
