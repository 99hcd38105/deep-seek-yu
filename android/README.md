# deep seek yu Android 客户端

此客户端通过电脑临时提供的安全链接连接局域网网关，不内置任何固定地址、端口或访问密钥。电脑和手机使用同一个 Harness 服务，因此会话和聊天记录保持同步。

首次连接失败时，点右上角“服务器”，填入 Windows 客户端菜单中显示的手机连接地址。

v1.1.0 正式版统一显示 `deep seek yu`，并可直接在 Harness 原聊天框用“＋”选择图片。图片通过带随机密钥的局域网连接进入电脑上的 Harness：官方支持图片的模型直接处理图片，文本模型则由电脑上的内部本地视觉服务生成描述后继续处理；手机不保存额外视觉 API Key，也不单独下载模型。
