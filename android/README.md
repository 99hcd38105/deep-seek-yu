# DeepSeek yu Android 客户端

此客户端通过电脑临时提供的安全链接连接局域网网关，不内置任何固定地址、端口或访问密钥。电脑和手机使用同一个 Harness 服务，因此会话和聊天记录保持同步。

首次连接失败时，点右上角“连接”，填入 Windows 客户端菜单中显示的手机连接地址；也可以使用“从剪贴板粘贴”。连接方式、随机端口和手机访问密钥与之前相同。

v1.1.1 测试版统一显示 `DeepSeek yu`。优化后的手机版提供底部导航、侧滑会话列表、全屏设置、键盘适配、连接状态和重新加载；工作区、会话、聊天、模型和 Harness 设置与电脑端保持一致。`设置 → 插件 → DeepSeek yu` 可以查看余额和服务状态、管理电脑桌宠、选择官方 Harness 版本，并搜索已验证目录、DSH Market 和 GitHub `dsh-plugin` Topic 的聚合插件市场；涉及安装的操作仍会在电脑端要求确认。

在 Harness 原聊天框用“＋”即可选择 Android 相册或文件中的图片。图片通过带随机密钥的局域网连接进入电脑上的 Harness：官方支持图片的模型直接处理图片，文本模型则由电脑上的内部本地视觉服务生成描述后继续处理；手机不保存额外视觉 API Key，也不单独下载模型。
